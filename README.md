# Dysphoric Sans

This font file is basically my own version of Noto Sans, meant to support Latin Extended-G and other additional Unicode characters.

## Note for all contributors and visitors
This is the very first time using GitHub, making this font extension to upload it to here.

Feel free to give feedback and suggestions so I can know if it needs any improvement! I've gotten better at making glyphs and smoother curves by self-teaching myself how to. The modifier glyphs are still not included, but I will add them when I have time to.

## Changelog
v2.0: Added almost the entirety of Latin Extended-G, including some glyphs in Latin Extended-D, E, and F.
v1.0: The very first version of the font.
